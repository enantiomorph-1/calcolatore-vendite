# Calcolatore netto vendite online

Sito statico gratuito per calcolare il guadagno netto dopo commissioni e spedizione su Vinted, eBay e Subito.

## Come pubblicarlo su GitHub Pages

1. Crea un repository pubblico su GitHub.
2. Carica tutti i file di questa cartella nella root del repository.
3. Vai in **Settings → Pages**.
4. In **Source** scegli `Deploy from a branch`.
5. In **Branch** scegli `main` e `/ (root)`.
6. Salva e attendi qualche minuto.

Il sito sarà disponibile all’indirizzo:

`https://TUO-USERNAME.github.io/NOME-REPOSITORY/`

## File inclusi

- `index.html`: calcolatore
- `privacy.html`: privacy policy
- `cookie.html`: cookie policy
- `chi-siamo.html`: pagina informativa
